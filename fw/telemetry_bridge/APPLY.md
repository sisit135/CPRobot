# Integrated telemetry and remote configuration

The telemetry addon and the remote configuration package are merged directly
into this firmware tree. No external archive or patch application step is
needed. For wiring, build commands, and storage precautions, see the repository's
[`docs/hardware_wiring.md`](../../docs/hardware_wiring.md), this directory's
[`README.md`](README.md), and [`docs/PROTOCOL.md`](docs/PROTOCOL.md).
